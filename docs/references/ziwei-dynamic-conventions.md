# 大限、流年与流月的独立预期

核查日期：2026-10-19。范围为 `createZiweiChart` 与 `generateZiweiScopes` 的本项目默认配置：年界及运限干支采用 `normal`，虚岁采用 `normal`，闰月十五分界。仅使用合成出生2000-08-16 02:30、经度120、纬度0、`Asia/Taipei`，分别按女性、男性计算；目标时间均为14:30民用时。

## 依据与采用方式

- 香港天文台[2000年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2000.pdf)给出生日期为庚辰七月十七。[2002年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2002.pdf)、[2012年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2012.pdf)、[2022年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2022.pdf)分别给出正月初一为2002-02-12、2012-01-23、2022-02-01；用于验证虚岁和大限交界，不用春节日期证明斗数安宫规则。
- 《紫微斗数全书》卷二[固定转录版本 oldid=1963110](https://zh.wikisource.org/w/index.php?oldid=1963110&title=紫微斗數全書/卷二#安身命例)的安命身、起五寅、纳音、安斗君、四化和主星表作为传统规则参考。转录页未注明影印底本，本文不声称已经完成古籍版本校勘。
- 大限从命宫起、局数为首限年龄、阳男阴女顺行等完整操作法，参考讲授者自行发布的[星林学苑《安大限与小限》](https://www.108s.tw/article/info/96)。独立实现 Fortel 固定提交 `2620cc895395f9f6994abd4927e739d31015c67d` 的 [`DestinyBoard`](https://github.com/airicyu/fortel-ziweidoushu/blob/2620cc895395f9f6994abd4927e739d31015c67d/src/model/destinyBoard.ts)中 `setupAgeRange`、`configDirection`、`getRuntimContext` 另可复核从命起限、十年一宫、流年在年支、流月斗君及五虎遁月干。没有把同一 iztro 引擎输出当作独立预期。
- 流月以斗君为正月顺行逐月一宫；月干采用流年五虎遁，不采用本命坐宫的宫干。这项流派选择也见 [iztro 官方安星诀第45节](https://www.iztro.com/learn/setup#_45-安子斗诀)的说明，但官方说明只证明所选语义，不作为独立安宫结果。

## 大限与流年

庚为阳干：阳女逆行、阳男顺行。虚岁以农历年差加一。2002为3岁，2012为13岁，2022为23岁；第十二限为113–122岁，因此2120、2121年分别为121、122岁，仍在第十二限。后两年只请求大限与流年，避免将仅有1–120岁的小限表当成大限寿命范围。

## 斗君、闰月与月干

生月七月从流年支逆数六步，生时丑再顺一步，故正月斗君在流年支逆五步：2025巳年在子，2026午年在丑。2025六月命宫从子顺五步到巳；七月再进到午。2026的正月至十月命宫依次为丑、寅、卯、辰、巳、午、未、申、酉、戌。

[香港天文台2025年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2025.pdf)给出普通六月初一6月25日、闰六月初一7月25日、十五8月8日、十六8月9日、末日8月22日、普通七月初一8月23日。按项目选择，闰六月前15天使用逻辑月6，十六起使用逻辑月7；宫位和五虎遁月干同时按此月序。乙年从戊寅起，所以月6癸未，月7甲申。**半月调整是本项目采用的现代约定，《全书》未直接载此流月分半方法；古籍闰月整月法不能充当其直接依据。** Fortel 的 `getRuntimContext` 同样按 `lunarDay > 15` 调整月干；它的流月宫位仍使用原月序，与本项目后半月宫位前进的选择不同，不能将二者整份动态盘视作同口径金标准。

[2026年表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)的正月至十月初一，依次为2月17日、3月19日、4月17日、5月17日、6月15日、7月14日、8月13日、9月11日、10月10日、11月9日。丙年寅首庚，逐月干支为庚寅、辛卯、壬辰、癸巳、甲午、乙未、丙申、丁酉、戊戌、己亥。这十个样本覆盖十天干四化，预期没有由程序重新排盘产生。

## 四化异文与验证范围

各层四化分别由该层天干触发，按祿、權、科、忌排列后，引用本命原星坐宫。甲、乙、丙、丁、戊、己、庚、辛、癸采用与上述《全书》转录相容的表；壬采用项目默认“天梁、紫微、左辅、武曲”。转录本的壬科是天府，故测试中左辅这一项属于明确固定默认表的兼容性验证，不宣称已获该古籍直接支持；它与天府在此盘恰好同在戌，也不能只检查落点而漏查星名。

自动对照覆盖：男女首三段及末段大限的宫位、干支、年龄范围与春节交界；指定流年的太岁命宫；十个普通月和六个闰月边界日期的斗君月命宫、五虎遁月干支；上述三层四化的星名、顺序与本命落点。没有独立验证所有动态辅杂星、十二神、亮度、流日流时、小限、所有日期或其他生辰；也不作命理解读。
